Job Scheduling System with Deadlines and Resource Constraints
About the Project
The Job Scheduling System is a Java-based project designed to schedule jobs efficiently by considering deadlines, processing time, job value, machine availability, and resource constraints.
Key Features
Add, view, and manage jobs.
- Schedule jobs based on their priority and value.
- Allocate jobs to multiple machines.
- Handle deadlines and resource constraints.
- Track completed and rejected jobs.
- Display scheduling results and performance analysis.
Technologies Used
- Java
- Java Swing
- Object-Oriented Programming (OOP)
- Greedy Algorithm
- Visual Studio Code
Algorithm
The system uses a value-based Greedy Algorithm to prioritize jobs and allocate them to available machines while satisfying scheduling constraints.
 Time Complexity
O(n log n + n × m)**
n – Number of jobs
m – Number of machines
